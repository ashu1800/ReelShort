# 播放器积分进度图标设计与实施记录

## 目标

将播放器右上角的长奖励胶囊收敛为紧凑的积分图标和观看进度圆环。圆环中心显示后端按本集权威时长和当前积分配置计算的预计基础积分，完成后继续显示实际到账提示。

## 设计

- 播放接口在现有字段之外返回 `estimatedRewardPoints`，但 `ContentVideo` 及播放地址缓存保持内容源原始数据，不保存运营配置派生值。
- Android 将新字段作为可空值解析；旧后端缺失字段时隐藏控件，避免展示不准确的本地估算。
- 控件使用 `16dp` 积分图标、`32dp` 确定型进度圆环和至少 `48dp` 点击高度，不显示外层胶囊或可见状态文案。
- 状态文案仅用于 TalkBack 和奖励说明弹层；圆心显示预计积分，实际到账继续使用现有短时浮层。

## 验收

- 后端连续播放请求会按当前配置重新计算预计积分，不从播放缓存复用旧值。
- Android 能解析新字段，并兼容缺失字段；切换剧集时预计积分随新的 `VideoUrl` 更新。
- 0%、播放中、完成、同步失败、日限额和不可用状态都保留确定型圆环与完整无障碍描述。
- 发布顺序为先部署 backend，再发布空更新说明的正式签名 Android `0.8.3 (36)`。
